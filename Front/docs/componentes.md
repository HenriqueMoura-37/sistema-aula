# Componentes

| Componente       | Responsabilidade                                      |
|------------------|-------------------------------------------------------|
| Header           | Exibir o título e a navegação principal               |
| Footer           | Exibir informações no rodapé                          |
| Botao            | Padronizar os botões reutilizáveis                    |
| FormularioPessoa | Formulário de cadastro e alteração de pessoas         |
| TabelaPessoas    | Listar pessoas, com botões de editar e excluir        |
